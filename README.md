# duska-score-feed

The Scorer's public feed for the duska.si experiment: how closely the AI-built tree agrees with the tree Kevin built himself.

Numbers only. No names, no dates, no places, no per-person results.

`feed.json` will appear here with the first scored snapshot, and this README will then explain each of its fields. No snapshot has been scored yet.

Rules: `rubric.md` in https://github.com/primerogueinc/duska-coordinator.

`.github/workflows/stamp.yml` is an unchanged copy of https://duska.si/stamp.yml. Every commit on `main` gets a manifest and an OpenTimestamps proof on the `proofs` branch.
